# @amarok-one/utils

Shared utility functions for AMAROK ONE.

Provides helpers for API responses, health checks, assertions, and common formatting logic.

## Usage

```ts
import { createApiResponse, createHealthStatus } from "@amarok-one/utils";
```

Depends on `@amarok-one/types`. Build before consuming from apps:

```bash
pnpm --filter @amarok-one/utils build
```
